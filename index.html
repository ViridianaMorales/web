DOM

Sus siglas significan MODELO DE OBJETOS DE DOCUMENTO, es una representación jerarquica de una pagina web que nos permite la interacción dinamica. ​

DOM CSS

Es un conjunto de APIs que permite manipular CSS desde JavaScript. Permite leer y modificar el estilo de CSS de forma dinámica. Dándole estilos y estética al contenido hecho en el DOM.

DOM eventos

Manipulación del documento para crear efectos visuales dinámicos.

DOM de animaciones

Es algo que ocurre y que el navegador detecta: un clic, mover el ratón, presionar una tecla, etc.

Significado de viewport

El viewport es la “ventana” por la que se ve la página web

Valores y unidades CSS

Tipos de datos en CSS

Tipo de datos Descripción
integer Un integer es un número entero, como 1024 o -55.
number Un number representa un número decimal; puede tener o no un punto de separación decimal con un componente fraccionario, por ejemplo: 0.255, 128 o -1.2.
dimension Una dimension es un number con una unidad asociada, por ejemplo: 45deg (grados), 5s (segundos) o 10px (píxeles).
percentage Un percentage representa una fracción de algún otro valor, por ejemplo, 50%.

Explicación sencilla del código de la clase 29/08

  • @property: Sirve para crear variables personalizadas en CSS (como --maria para un color y --tamaño para un tamaño de letra).
  • .caja: Es un div centrado que usa el color de fondo guardado en la variable --maria.
  • h1: El título usa la variable --tamaño para definir el tamaño de la letra.
  • .cajas: Es otro div similar, pero con fondo azul por defecto.
  • @media (max-width: 600px): Cambia el color de fondo de .cajas a verde cuando la pantalla es pequeña (por ejemplo, en celular).

Animaciones en CSS

Las animaciones en CSS permiten cambiar estilos de un elemento de forma progresiva. A continuación se explican algunas propiedades importantes:

Explicación

  • animation-name: Define el nombre de la animación creada con @keyframes.
  • animation-duration: Tiempo que dura un ciclo de la animación (ej. 3s).
  • animation-delay: Retrasa el inicio de la animación (ej. 2s).
  • animation-timing-function: Controla la velocidad de la animación (ej. ease-in, ease-out, linear).
  • animation-direction: Define si la animación se repite hacia adelante, en reversa o alterna (ej. alternate).
  • animation-fill-mode: Indica si el elemento mantiene los estilos de la animación antes o después de ejecutarse (ej. forwards).
